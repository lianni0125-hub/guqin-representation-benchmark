# Core Concept Operationalization v0.1

| Concept | Source-theory role | Domain-neutral core | Jianzipu operationalization | Required evidence/test | Main controls | Falsifier / rejection trigger | Prohibited inference |
|---|---|---|---|---|---|---|---|
| event/unit | carrier of a structured representation | a consistently identifiable object over which generalisations are stated | competing candidates: compound written token; attack-anchored event with dependent actions; pitch-change subevent; multi-level grouping | reversible segmentation, recurrence, dependency coverage, reviewer traceability | page order, scribal layout, omitted/repeated values | segmentation is unstable or cannot preserve alternatives | one glyph is inherently one note/phoneme |
| contrast | inventory distinctions required for phonological organisation | a distinction whose collapse removes a relevant generalisation | candidate distributionally nonredundant structural distinction | matched contexts plus feature-collapse comparison | source, piece/family, physical feasibility, graphic variant | effect disappears under controls or rests on circular categories | phonemic status, meaning contrast, minimal-pair equivalence |
| predictability | feature value supplied or constrained by context/rule | reduction of uncertainty given stated information | degree to which a target value is recoverable from permitted physical/notational/sequential context | conditional entropy, calibrated prediction, or explicit rule coverage | missingness, class imbalance, target leakage, source identity | instability across pieces or prediction uses unavailable/target information | cognitive absence, allophony, causal rule |
| specification | information represented rather than supplied elsewhere | information necessary to express a generalisation | retain/remove a feature in an analysis representation | ablation, collapse, exception and coverage analysis | model capacity and identical target | removal does not affect any defined generalisation | literal mental storage format |
| redundancy | information unnecessary relative to a task and context | recoverability without loss for stated explanandum | candidate feature value removable under a named context/model | feature removal plus out-of-piece test | deterministic physical mappings and notation conventions | loss of coverage/generalisation after removal | universal redundancy across all tasks |
| tier | partially autonomous representational dimension | values can vary/associate independently | pitch-relevant, attack/gesture, continuation/action dimensions | independence, non-isomorphism, one-to-many/many-to-one associations | richer input and duplicated columns | no empirical autonomy or benefit over flat encoding | literal autosegmental cognition |
| association | explicit link across dimensions | relation not captured by mere adjacency | links among written token, attack, pitch candidate, and dependent action | versioned association indices and alternatives | temporal/order assumptions | forced or always trivial one-to-one links | perceptual binding without evidence |
| economy | fit/coverage relative to representational cost | simpler adequate analysis preferred under an explicit metric | trade-off among held-out fit, rule coverage, feature/link count, parameters or description length | common targets, ablation, complexity accounting | unequal information, hyperparameter capacity | richer model wins only because cost is ignored | universal cognitive optimality |
| representation learning | induction of a representation from evidence | select/factor/merge/associate distinctions under an objective | interpretable search over R0–R5 and registered feature operations | grouped held-out fit, explicit cost, stability and audit trail | black-box capacity, post-hoc target choice, ambiguity | learned output is unstable, uninterpretable or no better than arbitrary encodings | neural/latent learning is required; learned structure is cognitively real |
| structural generalisation | recurring statement beyond item listing | compression/prediction over independent observations | rule or distribution holding beyond a single piece/source | out-of-piece/family evaluation and counterexamples | source tradition and duplicated versions | no transfer beyond training pieces | grammaticality judgement |
| phonotactics (reserved) | constraints on combinations of phonological units | restrictions over local/longer combinations | not used as a main label until RQ1 units and contrast are established | later-stage sequence evidence | frequency and physical feasibility | units lack stable combinatorial identity | corpus absence equals ungrammaticality |

## Terminology policy

- Main empirical term: `candidate structural contrast`.
- Main method term: `corpus-based computational experiment`.
- `phoneme`, `allophone`, `underlying form`, `grammar`, and `phonotactics` are reserved or explicitly qualified.
- `descriptive/analytical non-specification` is preferred to psychological `underspecification` for Paper 1 results.
